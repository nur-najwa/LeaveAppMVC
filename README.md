# Leave Application System (ASP.NET Core MVC)

A simple leave management system using ASP.NET Core MVC and SQL Server.

## Features
- Submit leave application
- Manager review, approve, reject
- Email notifications (MailKit)
- Basic form validation

## How to Run
1. Open solution in Visual Studio  
2. Update connection string  
3. Run `LeaveDB.sql`  
4. Start the app → /Leave/Create
